# Cheat Sheet

Enter a supported command name (`curl`, `git`, `docker`, `kubectl`, `openssl`,
`tar`, `jq`, or `ssh`) to see common usage examples. `cul` also selects curl.
Use `cheat:curl` or a directive on its own line, such as `::cheat=git` or
`git` followed by `::cheatsheet`, for explicit lookup. Unknown explicit topics
show the available commands.

Examples are bundled with the app and work offline. There is no network request,
shell execution, or download from cht.sh. Copy an example and replace angle-bracket
placeholders before running it. The Cheat Sheet tool is listed in Tools and can
be enabled or disabled in Settings.
